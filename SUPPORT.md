# Support

NextRDP is an early-access open-source project without a commercial support SLA.

- Use [GitHub Discussions](https://github.com/mikerte/nextrdp/discussions) for setup questions, usage help, and design ideas.
- Use [GitHub Issues](https://github.com/mikerte/nextrdp/issues) for reproducible bugs and scoped feature requests.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before asking for help, review the [desktop installation guide](docs/install-desktop.md), [development guide](docs/development.md), [self-hosting guide](docs/self-hosting.md), and existing issues.

When reporting a problem, include the Windows version, NextRDP commit or build version, relevant redacted logs, and exact steps. Never include passwords, tokens, certificates, private hostnames/IP addresses, exported production inventories, or unredacted support packages.
