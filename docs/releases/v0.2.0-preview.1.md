# NextRDP 0.2.0-preview.1

This is the first source-only NextRDP preview checkpoint. It records the working Windows desktop MVP and the self-hosted Phase 2 management preview before privileged-access work begins.

## Included

- Native Windows 11 x64 desktop client with tabbed Microsoft RDP sessions, local SQLite inventory, safe import/export, diagnostics, accessibility support, and prompt-only credentials.
- Compact, virtualized connection inventory, conventional application menu and toolbar, quick connect, favorites, recents, themes, and production-environment warnings.
- Self-hosted ASP.NET Core/PostgreSQL management platform with React administration, shared inventory, policy versions, synchronization, automation, audit, and encrypted backup/restore.
- A repeatable preview build that produces a self-contained x64 archive, a locally test-signed `NextRDP.Client` MSIX, SHA-256 hashes, and a machine-readable release manifest under ignored local artifacts.
- Isolated clean-install and upgrade smoke scripts for Windows 11 x64 test users.

## Distribution boundary

The GitHub pre-release contains source archives only. No MSIX, ZIP, certificate, or other binary asset is attached. Locally generated MSIX packages use a disposable development certificate and are suitable only for evaluation on test machines.

A production binary release still requires protected certificate custody, production signing, release approval, and the installer/deployment work tracked for the first enterprise release.

## Build the checkpoint locally

```powershell
git checkout v0.2.0-preview.1
.\scripts\build-preview-release.ps1
```

The output is written to `artifacts\release\v0.2.0-preview.1\`. See [desktop installation](../install-desktop.md) for the trust and installation boundary.

## Known limitations

- Windows 11 x64 is the certified desktop target; Windows 10 and ARM64 are not supported targets for this preview.
- Production signing and a production-supported installer are not available.
- Corporate OIDC, domain, RD Gateway, RemoteApp, multi-device, and redirected-device validation still depend on external infrastructure.
- The self-hosted management platform is an evaluation preview, not a supported production service.

## Security

RDP passwords remain in the Windows credential prompt. They are not accepted by NextRDP, stored in profiles, synchronized, exported, logged, or included in support packages.
